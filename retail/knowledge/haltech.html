THE INSTALLATION COMES FIRST

Plan the installation before chasing output.

First start or an existing tune?

A fresh installation needs a different appointment from a running car that needs refinement. Tell me whether the engine has started, what has been checked and who completed the wiring. Initial commissioning and full-load calibration should be scoped separately.

Match the software to the ECU

Nexus and Elite installations do not all arrive with the same software history. Send the ECU label, current software and map before updating firmware. Preserve the working configuration and discuss any migration as part of the job.

Fuel, ignition and control hardware

Include injector identification, fuel pressure arrangement, coil details, trigger configuration and throttle type. Those inputs define the calibration task. A base map can be a starting configuration, but it does not establish that the wiring or sensor readings are correct.

Where it fits

It can suit modified engines and conversions where the required inputs, outputs and control functions are matched to the build. My Haltech work includes Thomas’s STI.

Software and logging

Identify the ECU model and the software currently used with it. Nexus uses NSP; some Elite installations also use NSP, while others retain an ESP-based setup. Older Haltech generations have their own software requirements.

Send the current map and a native datalog from the same setup, with the software version and any fault messages. Check the required transfer format with me before converting or trimming files.

Should I update before the session?

Ask first if the car is on an older software or firmware version. A software migration is a separate setup task; it should be planned with the existing map and installation rather than treated as routine session preparation.

What to send Keith

  • Exact ECU model, software version and calibration file.
  • Engine and trigger details, injectors, coils and throttle type.
  • Wiring information, sensor specifications and recent logs.

If you are unsure which system you have, start with a photo of the ECU label and the details you know.

Before your tuning session

Use the software and manuals for the exact ECU generation. Have installation issues resolved before a tuning session, and include any warning messages or recent changes when asking for help.

Make the session productive.

  1. Send the existing record. Include the ECU label, current tune and logs, engine specification, wiring information and a description of the goal or fault.
  2. Agree on the scope. We distinguish installation checks, first-start work, drivability refinement and dyno calibration. Hardware, software access and unresolved faults can change the plan.
  3. Prepare the vehicle. Resolve leaks, misfires and known mechanical concerns. Confirm fuel, battery condition and the logging equipment. Follow the vehicle preparation checklist before the appointment.
  4. Review the result. Keep the agreed final file and instructions. Let me know before changing the hardware, sensors or fuel afterward.

Haltech planning questions.

Should I update from ESP to NSP before tuning?

Ask first. We need the exact Elite model, existing software, map and installation details before planning a migration. Updating just before a scheduled session can add configuration work that was not included in the original plan.

Can you supply hardware as well as tune it?

I offer ECU sales and project packages. Send your engine, intended use and existing equipment so we can confirm the hardware, accessories and calibration scope before quoting. Product photos are examples, not promises of stock or fitment.

Can this be handled remotely?

That depends on the installation, the work needed and the available data. Send the project details first. An unresolved wiring or mechanical issue may require hands-on checks before calibration can progress.

Can I use a dyno I have arranged?

Yes, subject to coordination. Confirm the location, equipment, operator, schedule and scope with me before booking. Travel and in-person work require planning and are quoted for the project.

Plan the next step

Tell me about your car, the equipment already installed and what you want to improve. I can review the setup before you order a tune or buy more parts.
