VINTAGE PORSCHE / 964 / KINSLER / STANDALONE ECUS

Three engine projects.
Individual calibrations.

My vintage Porsche work includes Kinsler-equipped engines using Emtron Shadow, MaxxECU and MoTeC. These are distinct projects with different throttle systems and engine specifications.

Discuss my vintage Porsche project →

964-based 4.0-liter / Emtron Shadow 8.

I calibrated this Ed Pink engine project using Emtron Shadow 8 and a Kinsler cable-throttle setup. This particular engine used cable throttle only; drive-by-wire was not part of this configuration.

For a project like this, the installed induction, injectors, sensors and ECU configuration form the starting point. Calibration needs to fit the engine and its intended driving experience.

Large-cam 964 / MaxxECU.

I tuned a separate Porsche 964 engine with large cams, MaxxECU and Kinsler drive-by-wire. My calibration work included injector setup, fueling and throttle behavior.

The cam specification matters to the tuning brief. This build should not be confused with the street-cam MoTeC engine below or the cable-throttle Emtron 4.0-liter project.

Street-cam 964 / MoTeC.

The MoTeC project was another 964 engine, using street-sized cams and Kinsler dual drive-by-wire control. I calibrated this engine around its own specification and intended use.

The goal is a complete driving experience: how the engine reacts to the pedal, transitions through load and delivers useful power. Choosing an ECU is one part of that work; integration and calibration have to suit the complete engine.

Planning with your engine builder.

I work with owners, restoration shops and engine builders to define the calibration scope and coordinate testing. Send the engine and cam specifications, throttle arrangement, injector information, fuel, installed ECU and available wiring or sensor documentation.

For an in-person session, we also agree on the location, dyno access, vehicle or engine readiness and responsibilities beforehand. Equipment, travel and calibration scope are quoted for the project.

Which route fits your Porsche?

These engines use standalone management. They are different from supported modern Porsche factory-ECU applications tuned through a COBB Accessport. If you are unsure which route applies, a short description of the car and installed system is enough to start the conversation.
