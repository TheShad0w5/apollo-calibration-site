MAKE THE FIRST REVIEW USEFUL

Send the setup, not just the symptom.

  • Vehicle and engine: year/model, engine combination, modifications and intended use.
  • ECU: model, software/firmware version and the current configuration file if available.
  • Fuel and sensors: fuel type, injector data, fuel-system arrangement and sensor models or calibration information.
  • The problem: whether it starts, when the behavior occurs, relevant changes, fault codes and what has already been checked.
  • Evidence: a log covering the event and available trigger/scope captures. Follow the agreed upload method for files.

Remote review can help identify the next check. It cannot physically verify wiring, mechanical condition or base ignition timing. Someone with the right equipment may need to perform those checks at the car.

Owners, builders and shops are welcome. Diagnostic scope, pricing, required data and any dyno arrangements are confirmed for the project; buying a standard tune does not include unlimited troubleshooting.

YOUR QUESTIONS

Before we get started.

Can a base map be used as a finished tune?

An initial configuration is a starting point that requires validation for the specific engine and hardware. Discuss the first-start and calibration process with Keith before running the engine under load.

Do I need to choose my ECU before contacting Keith?

No. Describe the engine, vehicle and intended use. You can discuss requirements and support availability before choosing equipment.

Can you help with a car another person has already tuned?

Describe the current setup and symptoms. Keith can assess whether a file review, diagnostics or a new calibration is the appropriate route, subject to available access and information.
